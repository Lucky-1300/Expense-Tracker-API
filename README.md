# Expense Tracker API

A small REST API for recording and reviewing personal or household expenses. It is suitable for a local budgeting workflow: records are kept in a readable CSV file, CRUD operations manage the source data, and analytics summarize spending by month, category, and overall statistics.

## Features

- Create, list, retrieve, update, and delete expenses.
- Store expense data in `data/expenses.csv`.
- Search by category or exact ISO date.
- Paginate and sort expense lists by approved public fields.
- Export the selected expense list as CSV.
- Produce monthly, category, and overall spending reports.
- Validate request bodies and query parameters with Pydantic and FastAPI.

## Technology Stack

- Python
- FastAPI and Uvicorn
- Pydantic validation
- Pandas and NumPy analytics
- CSV persistence using Python's standard library

## Setup

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### macOS or Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

The project does not require an additional test-only package. The test suite uses Python's built-in `unittest` module.

## Run the Server

From the project root, with the virtual environment active:

```powershell
python -m uvicorn app.main:app --reload
```

The API is available at `http://127.0.0.1:8000`. Interactive Swagger UI is at `http://127.0.0.1:8000/docs`; the OpenAPI document is at `http://127.0.0.1:8000/openapi.json`.

## API Endpoints

All dates use `YYYY-MM-DD`. Amounts must be greater than zero. Expense IDs are generated by the API and are not supplied by clients.

### CRUD

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/expenses` | Create an expense |
| `GET` | `/expenses` | List expenses, optionally filtered, sorted, and paginated |
| `GET` | `/expenses/{expense_id}` | Retrieve one expense |
| `PUT` | `/expenses/{expense_id}` | Update one or more expense fields |
| `DELETE` | `/expenses/{expense_id}` | Delete one expense |

Create request:

```json
{
	"title": "Groceries",
	"amount": 54.75,
	"category": "Food",
	"date": "2026-09-25",
	"notes": "Weekly shop"
}
```

Representative create response (`201 Created`):

```json
{
	"message": "Expense created successfully",
	"id": 1,
	"expense_id": 1,
	"expense": {
		"id": 1,
		"title": "Groceries",
		"amount": 54.75,
		"category": "Food",
		"date": "2026-09-25",
		"notes": "Weekly shop"
	}
}
```

Update request fields are optional:

```json
{
	"amount": 60.0,
	"notes": "Updated receipt"
}
```

### Search, Pagination, and Sorting

`GET /expenses` supports these query parameters. Filters are applied first, then sorting, then offset and limit pagination.

| Parameter | Values | Meaning |
| --- | --- | --- |
| `category` | non-empty text | Exact category match, for example `Food` |
| `date` | `YYYY-MM-DD` | Exact date match, for example `2026-09-25` |
| `limit` | integer `>= 1` | Maximum number of records |
| `offset` | integer `>= 0` | Number of sorted records to skip; default `0` |
| `sort_by` | `id`, `title`, `amount`, `category`, `date` | Approved sort field; default `id` |
| `order` | `asc`, `desc` | Sort direction; default `asc` |

Examples:

```text
GET /expenses?category=Food&date=2026-09-25
GET /expenses?sort_by=amount&order=desc&limit=10&offset=0
```

Representative list response:

```json
[
	{
		"id": 1,
		"title": "Groceries",
		"amount": 54.75,
		"category": "Food",
		"date": "2026-09-25",
		"notes": "Weekly shop"
	}
]
```

### Analytics

| Method | Endpoint | Response |
| --- | --- | --- |
| `GET` | `/reports/monthly` | Object mapping `YYYY-MM` to spending total |
| `GET` | `/reports/category` | Object mapping category to spending total |
| `GET` | `/reports/statistics` | Total, count, average, and highest expense |

Example responses:

```json
// GET /reports/monthly
{
	"2025-09": 20.0,
	"2026-09": 80.0
}
```

```json
// GET /reports/category
{
	"Food": 70.0,
	"Travel": 30.0
}
```

```json
// GET /reports/statistics
{
	"total_expenses": 100.0,
	"expense_count": 3,
	"average_expense": 33.33,
	"highest_expense": 50.0
}
```

Monthly totals use both calendar year and month, so September 2025 and September 2026 remain separate. Empty reports return `{}`; empty statistics return zero values without division by zero.

### CSV Export

`GET /expenses/export` downloads `expenses.csv`. It accepts the same `category`, `date`, `limit`, `offset`, `sort_by`, and `order` parameters as `GET /expenses` and applies them in the same order.

```text
GET /expenses/export?category=Food&sort_by=amount&order=desc
```

The response is `text/csv` with an attachment content-disposition and the columns `id,title,amount,category,date,notes`.

## Error Handling and Validation

- Invalid request bodies, dates, amounts, missing required fields, invalid pagination values, unsupported sort fields, and unsupported sort directions return FastAPI validation errors (`422 Unprocessable Entity`).
- A missing expense ID returns `404 Not Found`.
- CSV storage corruption or file errors return `500 Internal Server Error` with a storage error detail.
- CSV writes use atomic replacement for updates and deletes, while creates append a validated row.

## Run Tests
